사진편집에서 원장님이 직접 옮긴 글씨 위치·크기·폰트·스티커·선·도형을, 작업실 저장이나 인스타 발행 때 그대로 붙잡아 두고 다음 사진에 다시 씁니다. 최대 10개. 저장될 때 “이 작업을 한마디로” 이름이 자동으로 붙습니다. 작업실 설정 리뉴얼 포함.

⚠️ 디자인 목업입니다 — 아직 코드 안 건드렸어요. 화면·이름규칙·동작을 먼저 확인받으려고 만든 정적 HTML입니다. 아래 세 가지는 제가 추천안으로 그려 둔 것이니, 다르면 말씀해 주세요: ① 이름은 로컬 규칙(공짜·즉시·오프라인) ② 10개 꽉 차면 가장 안 쓴 것 자동 삭제(기본 지정된 건 보호) ③ 기존 _learnShopStyle 자동 덮어쓰기는 걷어내고 이 기억으로 일원화.

발행/저장을 누른 바로 그때. 팝업이 아니라 인라인 카드로 조용히 뜨고 사라집니다(3초). 원장님이 할 일은 없습니다.

10개가 꽉 차면

가장 오래 안 쓴 기억이 조용히 밀려납니다(lastUsedAt 기준). 원장님한테 안 물어봐요 — 발행 흐름을 끊지 않으려고요.

단, ★ 기본으로 고른 기억은 절대 안 밀립니다.

④ “한마디로” 이름 규칙

서버·AI 안 씁니다. 저장된 레이어를 읽어서 앱이 바로 조합해요 — 공짜·즉시·오프라인.

조합 공식

기억은 세 조각으로 이름을 만듭니다.

① 무엇을 — 시술명
↳ d.service 또는 제목 글씨에서. 없으면 생략

② 어떤 틀에 — 레이아웃 종류
↳ editState.layoutIdx → 전후비교 / 콜라주 N장 / 한 장

③ 어떻게 꾸며 — 가장 눈에 띄는 특징 하나
↳ 글씨 정렬·위치에서. 예) “글씨 아래 정렬”
속눈썹 전후비교,
글씨 아래 정렬
service:"속눈썹"
layout:ba
text×2 @y .60/.76 align:left
네일 가격표,
가운데 큰 제목
service:"네일"
layout:single
text×3 align:center size .085
헤어 3장 콜라주,
글씨 왼쪽 아래
service:"헤어"
layout:collage3
text×1 @y .84 align:left

짚고 갈 것 확인 필요

  • 브러시로 그린 그림은 기억 못 해요. 편집기에서 붓질은 벡터가 아니라 그 사진에 구워진 PNG(photoDraw)라, 다른 사진에 다시 못 올립니다. 요청하신 “선”은 선/도형 레이어로만 기억됩니다(이건 데이터라 재사용 O).
  • 기억 ≠ 내 레이아웃. 레이아웃은 사진이 들어갈 틀, 기억은 그 위 글씨·꾸밈. 지금 설정에선 둘 다 같은 ShopStyle 저장소를 써서 헷갈릴 수 있어, 목업에선 카드 설명으로 구분해 뒀습니다.
  • 10개 × 스티커 이미지가 localStorage 용량(5MB)을 밀 수 있습니다. 사진은 안 담고 레이어만 담을 계획이라 괜찮을 것 같지만, 실측 후 IndexedDB 이관 판단이 필요합니다.
