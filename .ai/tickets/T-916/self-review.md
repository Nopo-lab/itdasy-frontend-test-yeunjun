# T-916 시작 화면 브랜드 정정

사용자 요청: 앱 시작 시 잇데이 스튜디오가 보이는 브랜드 문제 정정.

- 변경: index.html 4줄, capacitor.config.json appName 1줄, BOARD, SESSION_STATE, 이 자가검토.
- 스크립트 로드 순서·전역·토큰·API·개인정보·결제·앱 권한·딥링크·인증서·서명 설정 변경 없음.
- 함수·기능 파일 변경 없음. 기존 큰 index.html에 문구만 정정하며 기능 인덱스 수정 불필요.
- 원격 main의 별도 복제본에서 작업하며 사용자 원본 변경을 포함하지 않는다.
- 다음 빌드의 표시 이름만 잇데이로 정정. 기존 내장 앱은 새 빌드가 필요할 수 있으며 스토어 제출·출시는 하지 않는다.
- 로컬 전체 검사: Mac 공간 부족과 파일 읽기 ETIMEDOUT/ECANCELED로 미완료. 운영 기능 오류라고 해석하지 않는다. GitHub의 배포 게이트 전체 검사를 확인하기 전 배포 성공을 주장하지 않는다.
- 좁은 변경 확인: 문구 5줄, JSON 유효, 기존 스크립트의 순서·원문 동일.

독립 검토 PASS: 원격 main과 스크립트 117개의 순서·원문 동일, 제품 문구 정확히 5줄, JSON의 appName 외 설정 동일, 초기 로딩·시작 화면에 Studio 표시 없음, diff 공백 검사 통과.
