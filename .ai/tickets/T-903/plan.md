# T-903 계획

1. 작업 폴더의 공유 `node_modules` 연결을 확인하고, 새 잠금 파일로 이 작업 폴더 전용 도구를 깨끗하게 설치.
2. 동기화 전 네이티브 식별자·딥링크·권한·서명 설정을 기록.
3. `npx cap sync` 실행 후 바뀐 파일을 검사해 Android/iOS 식별자와 `itdasy://`가 유지되는지 확인.
4. Android debug APK와 iPhone 시뮬레이터용 앱을 빌드. 스토어 제출용 서명·버전 번호는 사용하지 않음.
5. 가능하면 현재 켜진 에뮬레이터·시뮬레이터에 설치해 시작 화면과 즉시 종료 여부 확인.
6. 검사 결과·남은 실물 기기 한계를 기록하고 독립 검토 후 커밋.

## 안전 기준

- Android `com.y2do.itdasy`, iOS `com.nopolab.itdasy`, 딥링크 `itdasy://` 유지.
- `android/app/build.gradle`, iOS 권한·서명·팀 설정의 의도치 않은 변경은 적용하지 않음.
- 운영 서버 요청이나 실제 로그인 없이 시작 여부만 확인.
- 빌드 산출물은 로컬 확인용이며 스토어에 업로드하지 않음.
