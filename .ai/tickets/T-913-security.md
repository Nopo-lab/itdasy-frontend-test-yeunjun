# T-913 보안 보강

사용자 승인: 2026-09-22 "응 해결해. 심사 전 웹전환 제외하고 나머지는 끝내둬."

앱 내장 전환·웹 폐쇄·스토어 제출은 제외한다. 로그인/개인정보 보안 수정은 승인됨.
운영 DB 직접 조회 금지 규칙을 유지하며 로컬 격리 DB에서 검증한다. 실제 환경의
권한·열쇠 교체는 연결 수단 및 심사 계정 연속성 확인 후 범위를 확정한다.

## 실행계획

1. 기존 미완료 T-912 변경을 보존하고 검토한다.
2. 1회용 값 사용 기록은 DB 실패 시 거부, 비밀번호 재설정과 기록은 같은 트랜잭션으로 처리한다.
3. 인스타 및 관리자 연결에서 장기 로그인값 URL 사용을 제거하고 소비자도 함께 변경한다.
4. 토큰 종류/만료/사용자 상태 검사를 강화하고 세션 개선의 클라이언트 호환성을 검증한다.
5. 고객정보 로컬 보관, 공개 시험자료, 하드코딩된 비밀번호를 정리한다.
6. DB 직접 API 차단 및 최소 권한용 재현 가능한 변경과 검증을 준비한다.
7. 자동 검사와 독립 검토 후, 배포/키 교체/외부 보안검사 중 완료와 미완료를 정확히 기록한다.

## 파일 크기/분리 판단

독립적인 보안 유틸리티와 검사를 분리한다. 기존 큰 파일은 필요한 연결 부분만 변경한다.
