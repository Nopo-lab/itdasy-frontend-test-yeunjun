# T-904 인스타 연결·앱 복귀

실제 화면 Invalid redirect_uri를 기준으로 Meta 등록 주소와 테스트 서버 주소를 대조한다. 키 값 없이 누락된 기존 Secret Manager 연결을 복구한다.

네이티브 외부 로그인 창 열기 실패를 기다려 처리하고, 연결 결과 복귀 후 창 닫기와 출발 표시 정리를 수행한다. 서버의 만료·취소 복귀와 URL 인코딩을 검사한다. 기존 로그인 표 직접 URL 저장 경로는 만들지 않는다. 운영은 제외한다.

자동 검사와 독립 검토 후 테스트 배포, 실제 외부 로그인 연결 및 복귀를 확인한다. 실기기 미확인은 분리 보고한다.
