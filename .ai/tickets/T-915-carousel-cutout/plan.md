# T-915: 여러 장 누끼 결과 보존

대상: 연준 테스트 프론트만. 운영 변경 없음.
실제 배포본 0c54cd9에서 합성 네일 2장 → 첫 사진 누끼/분홍 배경 → 둘째 사진에서 완료 → 첫 사진이 원본 검정 배경으로 돌아옴을 재현.

1. 비활성 사진의 완전한 편집 상태를 합성과 저장에 사용.
2. 재열기에서 누끼 원판/마스크/보정/그림/최신 글자 보존.
3. 과거 단일 상태와 미편집 사진이 섞인 경우 상태 격리.
4. 관련/전체 검사, 독립 검토, 브라우저 합성 결과 재검증. 외부 전송은 합성 사진만.

이 변경은 기존 큰 플로우 파일의 연결부 6줄만 수정. 복원 처리는 기존 500줄 미만 photo-recipes에 분리. 스크립트 순서, 새 전역, 토큰/접속 주소, 기존 워크플로 변경 없음.
