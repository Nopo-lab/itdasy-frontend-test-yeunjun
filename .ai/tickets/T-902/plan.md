# T-902 계획

1. DM 예약 카드의 확정 문구·시술 시간·주소가 채널 이동에서 사라지는지 실제 화면 구조로 재현.
2. 일반 답글 보존소를 예약 카드 값까지 담도록 작게 확장하고 계정 변경 시 함께 삭제.
3. 신규 검사와 전체 자동 확인으로 기존 발송 자료가 유지되는지 검증.
4. 수정 답장에 시술시간을 넣어 보내는 경우 서버 입력과 예약 실행 함수까지 전달되는지 확인하고 누락을 함께 수정.
5. 보안 경고는 임시 복사본에서 갱신 결과를 확인하고 필요한 최소 버전 범위를 반영.
6. 휴대폰 설정 파일은 변경하지 않고, 양 플랫폼 빌드가 필요한 부분은 미검증으로 기록.

## 구현 전 확인

- `index.html`, 로그인 토큰, DB·외부 발송 경로 변경 없음.
- 기존 큰 DM 파일은 작은 보존 함수만 수정하고 새 검사는 별도 파일에 작성.
- 개발 도구 변경은 실행용 앱 부품과 구분하고 잠금 파일까지 함께 기록.
