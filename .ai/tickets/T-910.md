# T-910 느린 연결의 잘못된 캐시 초기화

## 결함

화면 맨 위에서 시작한 1.5초 타이머가 `app-core.js` 다운로드 완료 전에 끝나면 정상 파일도
로드 실패로 오인해 캐시와 서비스 워커를 지우고 앱을 다시 열었다. 실제 배포 화면의 오류 기록과
해시 화면이 홈으로 되돌아가는 현상으로 재현했다.

## 수정

모든 동기 스크립트의 성공 또는 실패가 확정되는 `window.load` 뒤에 한 번만 버전을 확인한다.
파일이 정말 없거나 버전이 다를 때의 기존 복구 동작은 유지한다.

## 검증

- 느린 로딩 중에는 캐시 삭제와 새로고침 0회
- 로드 완료 뒤 파일 버전이 없으면 기존 복구 1회
- 화면 전체 검사 209묶음, 3,224개 성공, 2개 제외
- 배포 구조 검사 성공
