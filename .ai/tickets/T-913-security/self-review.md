# T-913 자가검토 (로컬 검증 완료, 배포 검증 별도)

- 사용자 보안 수정 승인 확인. 앱 내장 전환/웹 폐쇄/스토어 재제출 제외.
- index.html 연결 순서 및 Capacitor 설정 변경 없음.
- 고객 조회 사본만 sessionStorage로 전환. 미전송 오프라인 원본/작성 중 문서는 보존.
- 토큰은 기존 getToken/setToken 경계로만 사용. native 실패·동시성에 동작 검사를 추가.
- 새 기능 전역 API 없음. 새 캐시 변경 알림은 고객정보 없이 종류·시각만 포함.
- 서버 nonce·비밀번호 재설정·token purpose·inactive 계정·admin websocket 실제 호출 검사.
- 실제 PostgreSQL 독립 5개 검사 통과: public 권한 경계, Storage 보존, 동시 재설정, rollback.
- FE 자동 검사 오류 0개/기존 경고 177개. 전체 221묶음 3,288개 통과 후 독립 동작 검사 21개 추가(해당 파일 27개 통과).
- 서버 전체 4,774개 통과 후 갱신 검사 2개 추가(해당 파일 16개 통과). PG 전체 221개 통과.
- 독립 검토 지적(교차창 계정전환, 늦은 응답, 갱신 중 만료) 수정 후 재현 검사 통과.
- 운영 고객 DB 직접 조회 없음. Supabase 보안 advisor 메타데이터로 76표 RLS 확인(INFO only).
- QA 계정 비밀번호 변경 완료. 새 값은 OS 안전 저장소에만 저장, 옛 값 거부/새 값 로그인 검증.

## 파일 크기/분리 판단

DB 권한 경계·보안 검사 별도 파일. 기존 큰 파일은 로그인/조회 사본 처리만 수정.
최종 파일 목록과 검증/배포 상태는 verification.md에서 확정한다.

1. 파일 목록: 보안 커밋에 명시적으로 선택한 로그인/조회 모듈, 검사, 제출문서, QA29개, 배포 제외 설정. 무관한 output 자료 제외.
2. index.html 연결 순서 변화 없음.
3. 새 전역 API 추가/삭제 없음. 기존 getToken/setToken 사용.
4. 기존 환경별 토큰 키 경계 유지. 비밀값 없는 차단 표시/창 알림만 추가.
