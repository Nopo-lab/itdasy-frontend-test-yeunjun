# T-904 실행계획

1. 최신 main과 승인된 T-901~T-903 변경을 별도 작업 폴더에 통합한다.
2. 위험 검사 도구에 대상 확인, 운영 차단, 빈 실행 차단, 개인정보 제거를 추가한다.
3. 코드에서 기능·API·DB·외부 연결·권한·돈·개인정보 지도를 다시 만든다.
4. 격리 PostgreSQL에서 권한 분리, 돈 중복, 장애, 복원, 성능을 실행한다.
5. 전용 시험샵에서 가입·로그인·고객·예약·사진·AI·Instagram·결제를 실제로 확인한다.
6. 합성·사용 허가 사진 60장 이상과 스타일 6종×10장 결과를 평가한다.
7. 결함마다 재현 검사→수정→전체 관련 검사→실제 흐름 재검증을 연결한다.
8. 최신 배포 버전을 다시 확인하고 G1~G25와 남은 사람 확인 항목을 최종 판정한다.

## 승인

사용자가 2026-09-15에 계획 전체와 이후 필요한 작업을 명시적으로 승인했다.
