# T-912 실행계획

1. 로그인 값이 주소·브라우저 일반 저장소로 새는 실제 경로를 검사로 먼저 고정한다.
2. 인스타 연동은 로그인 확인값이 붙은 1회용 표만 허용하고, 실패하면 연동을 멈춘다.
3. 휴대폰에서는 앱에 이미 들어 있는 안전 저장 기능을 직접 호출하고, 실패 시 일반 저장소에 로그인 값을 쓰지 않는다.
4. 소셜 로그인 복귀도 공통 로그인 저장 함수를 사용한다.
5. 웹 복귀 페이지는 스테이징 값만 저장하고, 복귀 주소가 외부 사이트로 전달되지 않게 한다.
6. 관련 검사, 전체 자동 검사, 앱 파일 연결 검사를 실행한다.
7. 실제 고객 데이터·운영 배포는 건드리지 않고 결과를 인수인계 문서에 남긴다.
