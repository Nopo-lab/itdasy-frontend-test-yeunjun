# T-911 캡션 생성 동의 누락 오류

## 증상

AI 처리 동의가 없는 계정에서 캡션 생성 시 안내와 재시도 대신 `consent_missing` 오류가 표시됐다.

## 원인

기본 캡션, 즉석 캡션, 음성 캡션, AI 비서의 캡션 요청이 공통 요청 통로를 거치지 않고 서버로 바로 전송됐다.

## 수정

- 모든 캡션 요청을 공통 요청 통로로 연결한다.
- 서버가 동의 누락을 반환하면 제공자와 처리 내용을 안내한다.
- 사용자가 동의하면 동의를 저장한 뒤 원래 요청을 한 번만 다시 보낸다.
- 계정이 바뀌면 이전 계정의 동의를 저장하거나 요청을 재시도하지 않는다.

## 확인

- 관련 자동 시험
- 전체 화면 자동 시험
- 배포 후 cbt4 시험 계정의 실제 캡션 생성
