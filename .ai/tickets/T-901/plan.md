# T-901 계획

1. 현재 기능 인덱스와 실제 로드 경로 대조. 기존 사용자 작업 app-plan.js 및 미추적 자료 보존.
2. 전체 자동검사·테스트·파일 연결·뒤로가기, 외부 연결 차단한 로컬 화면 점검.
3. 현재 I​tdEditor/작업실 저장·복원·실패·접근성 점검; T1은 DM·댓글·잇비 독립 검토.
4. 재현되는 일반 프론트 오류만 최소 변경, 회귀 테스트와 독립 리뷰. 개인정보·결제 로직은 조사 결과만.
5. 공식 Apple/Google/Meta 기준 확인, 전체 범위표·확인/미검증 구분·핵심 기능 개선안·90일 실행계획 작성.
6. 검사 결과와 변경 목록을 self-review와 SESSION_STATE에 기록. 운영 push나 실발송 없이 검토 가능한 커밋 제공.

## 자가 검토 (구현 전)
- index 로드 순서·네이티브 설정·기존 Actions 미수정.
- 토큰 저장소·전역 추가·개인정보 저장 방식 미수정 예정.
- 큰 파일은 최소 수정; 새 테스트/도구는 독립 실행 가능한 역할로 구성.
- 테스트 결과는 실행 후 기록하며 통과를 선기재하지 않음.
