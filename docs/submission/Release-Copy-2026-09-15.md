# 잇데이 스토어 소개 — 검토용 초안

사진편집·글 만들기·문의 답글 검토·예약 관리의 기존 기능을 중심으로 썼다.
심사에 제출할 설치본에서 기능과 화면이 일치하는지 마지막으로 확인한다.

## 한국어 공통 소개

**앱 이름:** 잇데이 - 1인샵 AI 비서

**App Store 부제:** 시술 사진부터 손님 응대까지

**Play 짧은 소개:** 시술 사진을 홍보물로, 손님 문의를 답글 초안으로. 1인 뷰티샵의 사진·글·예약 관리를 한곳에서 도와드립니다.

**App Store 프로모션 문구:** 사진을 꾸미고, 내 샵에 맞는 글을 만들고, 손님에게 보낼 답글을 검토하세요. 잇데이가 1인 뷰티샵의 반복 업무를 도와드립니다.

### 상세 설명

혼자 운영하는 뷰티샵, 시술 외에도 할 일이 많으시죠?
잇데이는 시술 사진 정리부터 홍보 글 작성, 손님 문의와 예약 관리까지 도와주는 AI 비서입니다.

**시술 사진을 내 샵의 홍보물로**
사진에 글자와 스티커를 더하고, 원하는 구도로 편집하세요. 저장한 작업을 다시 열어 다듬을 수 있습니다.

**내 샵에 맞는 글 초안**
사진과 전달할 내용을 바탕으로 홍보 글을 준비하세요. AI가 만든 문장은 직접 확인하고 내 말투로 수정할 수 있습니다.

**손님 문의에 답할 준비**
연결된 인스타그램 계정의 지원되는 댓글과 DM을 확인하고, 보낼 답글을 검토·수정하세요. 기능 이용에는 계정 연결과 필요한 권한이 요구됩니다.

**말로 시작하는 업무, 잇비**
필요한 일을 잇비에게 입력하고 안내를 받으세요. 실행할 내용과 결과를 확인하며 고객·예약·매출 업무를 정리할 수 있습니다.

**하루 운영을 한곳에서**
예약 일정과 고객 기록, 매출을 살펴보고 다음에 할 일을 준비하세요.

일부 기능에는 유료 구독, 인터넷 연결 또는 외부 서비스 계정이 필요합니다. 외부 서비스의 권한과 이용 조건에 따라 지원 범위가 달라질 수 있습니다. AI 결과의 가격·날짜·표현은 사용 전에 확인해 주세요.

## 첫 스크린샷 구성

| 순서 | 제목 | 보여줄 실제 화면 |
|---|---|---|
| 1 | 시술 사진으로 오늘 홍보 준비 | 가상 시술 사진으로 만든 완성 홍보물과 편집 화면 |
| 2 | 내 샵 말투로 다듬는 글 | 생성된 글과 수정할 수 있는 입력칸 |
| 3 | 손님에게 보내기 전, 한 번 더 확인 | 가상 문의와 수정 가능한 답글 |
| 4 | 말로 시작하는 오늘의 업무 | 잇비의 실행 전 확인 카드 |
| 5 | 예약과 고객 기록을 한곳에서 | 가상 일정과 고객 기록 |

실제 고객 이름·연락처·대화·사진은 사용하지 않는다. 사진 모델과 이미지 사용 권리를 확인한다.
첫 장은 사진 중심/문의 중심 두 안을 나중에 스토어 실험으로 비교한다.
