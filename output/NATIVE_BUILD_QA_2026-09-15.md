# iPhone·Android 동기화와 빌드 확인

작성: 2026-09-15 · T-903 · 사용자 네이티브 작업 승인 완료

## 판정

**최신 스테이징 잇비 수정까지 합친 뒤 동기화, 양쪽 시험용 빌드, 켜져 있던 시험 기기 설치까지 통과했다.**
기존 시험 기기에 로그인 정보가 남아 있을 수 있어 앱 실행과 화면 조작은 하지 않았다.
스토어 제출용 서명, 실제 휴대전화, 시험 결제, 실제 메시지 발송은 이번 확인에 포함하지 않았다.

## 동기화로 바뀐 파일

추적되는 변경은 `ios/App/Podfile.lock` 하나다.
CordovaPlugins 잠금 버전과 확인값이 8.5.0에서 8.5.2로 맞춰졌다.
Android 앱 이름, iPhone 앱 이름, 로그인 돌아오기 주소, 권한, 서명 팀 설정은 바뀌지 않았다.

## 처음 멈춘 이유와 처리

- Android: 기본 Java 25는 빌드 도구가 읽지 못했다. Java 17로 바꿔도 프로젝트가 요구하는 Java 21이 없어 멈췄다. Java 21을 개발 도구로 설치하고 빌드에만 지정해 통과했다.
- iPhone: 지정한 운영체제 버전이 26.4였지만 실제 시뮬레이터는 26.4.1이었다. 기기 고유번호를 지정해 통과했다.

두 실패는 앱 기능 오류가 아니라 이 컴퓨터의 빌드 도구 선택 문제였다. 실패 기록도 로컬 결과 폴더에 보존했다.

## 출시 전에 남은 확인

1. 실제 iPhone과 중저가 Android에서 로그인, 카메라·사진 권한, 앱 중단·복귀, 뒤로가기를 확인한다.
2. App Store와 Play의 시험 결제에서 구매·복원·취소·갱신을 확인한다.
3. 별도 시험 계정과 격리된 시험 서버에서 댓글·DM 실제 발송 결과를 대조한다.
4. 스토어 제출용 서명과 버전 번호, 개인정보 안내, 심사 계정을 최종 대조한다.

## 파일 크기/분리 판단

실행 코드는 추가하지 않았다. 동기화가 갱신한 잠금 파일 한 곳과 결과 문서만 남겼다.
새 큰 파일이나 50줄을 넘는 새 함수가 없고, 초기 파일 불러오는 순서도 바꾸지 않았다.
